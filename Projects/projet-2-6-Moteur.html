Moteur de jeu

Moteur OpenGL en C++ organisé autour d’une architecture ECS.

Voir sur GitHub

Introduction

Ce projet consiste à développer un moteur de jeu OpenGL en C++ en s’appuyant sur une architecture Entity Component System.

Contenu

  • Architecture ECS pour organiser les entités et leurs composants
  • Rendu OpenGL et gestion des ressources graphiques
  • Gestion des scènes, transformations et caméras
  • Organisation d’une base technique réutilisable pour des jeux

Compétences

  • Programmation C++
  • OpenGL
  • Architecture Entity Component System
  • Rendu 2D et 3D
  • Organisation d’un moteur de jeu

Détails

  • Création d’un moteur de jeu en C++ avec une architecture ECS.
  • Gestion des entités, composants et systèmes de jeu.
  • Intégration du rendu OpenGL et des ressources graphiques.
  • Projet conçu comme une base pour de futurs prototypes.
