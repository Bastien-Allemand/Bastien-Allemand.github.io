Cryptage d’image

Application Windows permettant de cacher puis de retrouver un caractère dans une image.

Voir sur GitHub

Introduction

Application Windows consacrée à la dissimulation et à la récupération d’un caractère dans une image.

Contenu

  • Chargement d’une image avec GDI+
  • Écriture d’un caractère dans les bits de poids faible du canal bleu
  • Lecture des 8 premiers pixels pour reconstruire le caractère
  • Enregistrement de l’image modifiée au format PNG

Compétences

  • C++ sous Windows
  • GDI+ et manipulation d’images
  • Opérations bit à bit
  • Gestion des codecs et des fichiers PNG

Détails

  • Application Windows utilisant C++ et GDI+.
  • Dissimulation d’un caractère dans les bits de poids faible du canal bleu.
  • Utilisation des 8 premiers pixels de l’image pour stocker le caractère.
  • Export de l’image modifiée au format PNG et récupération du caractère par lecture des pixels.
