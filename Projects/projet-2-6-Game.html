3D Horror Game

Projet de jeu en C++ destiné à expérimenter un prototype de jeu 3D et ses futures mécaniques de gameplay.

Voir sur GitHub

Introduction

Ce projet représente une étape de pratique supplémentaire pour tester de nouvelles idées de gameplay et de structure.

Contenu

  • Base de code organisée entre les ressources, la configuration et les sources
  • Prototype de mécaniques de jeu
  • Organisation prévue pour de futurs systèmes de gameplay
  • Développement d’un jeu 3D en cours

Compétences

  • C++
  • Conception de gameplay
  • Programmation C++
  • Notions de shader avec HLSL
  • Organisation d’un projet de jeu

Détails

  • Projet de jeu en C++ avec une base de code organisée en dossiers bin, config, res et src.
  • Prototype destiné à expérimenter les mécaniques et la structure d’un jeu.
  • Projet en cours de développement, prévu pour accueillir de futurs systèmes de gameplay.

Durée

1 mois.

Équipe

Projet trio.
